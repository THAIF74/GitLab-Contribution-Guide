## Contribution principles

- Link to the original issue and upstream work.
- Separate verified facts from suggestions and open questions.
- Do not claim a change is implemented, accepted, merged, or rewarded unless the upstream project confirms it.
- Keep this repository as a transparent record; upstream changes must be submitted to and reviewed by the relevant GitLab project.
